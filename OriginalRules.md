Итак, есть некое поле, в котором 888 слотов. И есть 5 первоначальных видов, каждый представитель занимает отдельный слот. На старте существует по 5 представителей каждого вида - красные, чёрные, белые, синие и жёлтые.

На очередном шаге игры любой представитель любого вида может совершить одно действие из двух: произвести с кем-то потомство (1 шт) или убить кого-то (тоже 1 шт). Размножаться можно только если на поле остались свободные клетки.

Завершением игры будет одно из трёх состояний:
- полностью заполненное поле (неважно кем);
- поле, где заполнено менее 5 слотов (вымирание);
- 555 или более слотов поля заполнены представителями одного вида (исходного или гибридного).

Для краткости одного представителя любого вида назовём чибик.
Каждому виду свойственно своё уникальное поведение, которое я распишу далее.

Общие правила:
1) когда один чибик выбирает другого для размножения, тот может быть согласен или нет (исходя из видовых особенностей). Если партнёр не согласен, то возможны два равновероятных исхода: размножение происходит (типа, изнасилование) или второй чибик убивает первого (ибо резко против того, чтобы с ним размножаться).
2) когда два чибика размножаются и порождают третьего, все трое оказываются на текущем ходу заблокированы для размножения с другими чибиками (те не могут их выбрать). Зато убить их можно.
3) любой чибик всегда согласен размножаться с представителями своего вида.
4) при размножении чибиков разных видов может получиться чибик цвета одного из родителей либо гибридный. Гибридные виды получаются только при смешивании исходных видов, при размножении двух гибридов всегда выходит чибик цвета родителя (вероятность выбора цвета 50/50). Если разможаются чибики двух исходных видов, с 50% вероятностью потомок будет гибрид, и по 25% вероятности на цвет каждого родителя.
5) гибридные виды:
красный + синий = фиолетовый
красный + жёлтый = оранжевый
красный + белый = розовый
красный + чёрный = бордовый
синий + жёлтый = зелёный
синий + белый = голубой
синий + чёрный = тёмно-синий
жёлтый + белый = светло-жёлтый
жёлтый + чёрный = коричневый
белый + чёрный = серый

Синие: Размножаться, помимо своих, предпочитают с белыми и жёлтыми (100% согласие, по своей инициативе не будут размножаться с другими цветами, если доступны эти). В качестве принимающей стороны 100% согласие на размножение.

Гибриды: со своим цветом или одним из родительских 100% согласие на размножение, с остальными цветами 50/50. По своей инициативе не убивают.
