# План и архитектура (game8885)

## Цель

Zero-player симуляция "Игра 8885" (см. `OriginalRules.md`): поле 888 слотов,
5 исходных видов, размножение/убийство, гибриды, поведение видов, условия
завершения. Правила формализованы в DSL (`rules/*.rule`), симуляция на Haskell,
UI на WebSocket + ApexCharts.

## Интерпретация правил (решения)

1. **Шаг** — каждый живой чибик выполняет ровно одно действие (размножиться
   или убить) в случайном порядке. Подтверждено пользователем.
2. **Блокировка (правило 2)** — после размножения оба родителя и ребёнок
   помечаются заблокированными до конца хода: их нельзя выбрать партнёром,
   но можно убить; сами они действовать могут.
3. **«Заняты» у белых** — «свои уже все заняты» = все белые заблокированы
   (только что размножались). Белый инициирует с другим чистым цветом только
   если белых < 5 и нет свободного белого партнёра.
4. **Жёлтые** — выбирают красного и жёлтого с равной вероятностью; если их
   нет — любого другого.
5. **Смешанное потомство** — исходный x исходный: 50% гибрид, 25/25 родители;
   гибрид x гибрид и исходный x гибрид: 50/50 цвет одного из родителей.
6. **Белые убивают** — только не-белых чибиков, которые только что
   размножились с чужим цветом («своих не убивают»).
7. **Синие убивают** — только доминирующий вид (при равенстве — случайный из
   максимумов), исключая себя, зелёных и голубых.
8. **«Своих гибридов» у чёрных** — гибриды, содержащие чёрный (тёмно-синий,
   коричневый, бордовый, серый).
9. **Партнёр выбирается по видам** (вид-равномерно внутри набора), **жертва —
   по особям** (взвешено по численности). Правило 4 для жёлтых требует
   видового уровня, поэтому партнёр — вид-равномерно.
10. **Согласие** (симпатия): свои всегда 100%; иначе первое подходящее
    правило DSL; иначе 50/50 по умолчанию. Отказ → 50/50: изнасилование
    (рождение) или партнёр убивает инициатора.

## DSL (правила)

Подробное описание языка правил с примерами — в `LANGUAGE.md`.

Секции: `Базовые виды`, `Синонимы` (гибриды), `Параметры` (Поле, Начало,
Победа, Изнасилование, Максимум шагов), `Цвета`, `Действия` (вероятность
убийства; `~смешанные~` для белых), `Партнёры` (предпочтения инициатора),
`Убийство` (цели и исключения), `Симпатии` (согласие принимающей стороны),
`Рождение` (исходы). Специальные токены: `*`, `~я~`, `~родители~`, `~чистый~`,
`~гибрид~`, `~доминирующий~`, `~смешанные~`. Условия: `[Вид < N]` и т.п.

Полные правила игры — `rules/8885.rule`; сбалансированный вариант с
обоснованием изменений — `rules/8885A.rule` и `ChangeLog.md`;
пример — `rules/example.rule`. Статистический инструмент балансировки —
`tools/balance.hs`.

## Модули

- `Species.hs` — типы: вид (чистый/гибрид), действие, поле (население,
  свободные слоты, заблокированные, «смешанные»), параметры среды.
- `Pattern.hs` — паттерны и контекстное сопоставление, типы правил, `Tables`.
- `Sim.hs` — симуляция: выбор действия/партнёра/жертвы, согласие, рождение,
  изнасилование, условия завершения, `stepTurn`.
- `Decl.hs` — декларации DSL и компилятор (правила → `Tables`).
- `Parser.hs` — парсер DSL.
- `Cmd.hs` — протокол WebSocket (`init/start/pause/restart/step/select/list`,
  сообщения `hello/init/state/error`).
- `Ctx.hs` — состояние игры, тикер автошагов, обработка команд, рассылка.
- `Server.hs`, `MainPage.hs` — HTTP-сервер Snap и страница (управление +
  статус + график).
- `Test.hs`, `TestMain.hs` — тесты (вероятности рождения 50/25/25, 50/50,
  симпатии, инварианты, полные партии).
- `public/js/main.js` — UI (переписывается отдельной задачей).

## Исправленные ошибки исходного кода

- `rapeAction`: использовала `killRatio` вместо 50/50; при отказе «умирал» не
  тот чибик и свободное место уменьшалось вместо увеличения.
- `killAction`: вероятность убийства сэмплировалась дважды; население
  менялось неверно.
- Отсутствовали: проверка свободных слотов, блокировка (правило 2), трекинг
  «смешанных», условия завершения, интерпретатор правил.
- Парсер молча обрезал секции при ошибке (добавлен `eof`, `;` после строк);
  имена с дефисом (`Тёмно-синий`); параметр `Максимум шагов`; синонимы не
  нормализовались (`mix`).
- Проценты в `Симпатиях` трактовались как веса (50% → 100%) — теперь это
  абсолютные вероятности.

## Сборка/запуск

Корневая ФС может быть read-only (stack не пишет в ~/.stack) — сборка
напрямую GHC из снапшотов: `./build.sh`, `./test.sh`, `./run.sh`
(сервер на http://127.0.0.1:8000). В writable-окружении: `stack build`.
